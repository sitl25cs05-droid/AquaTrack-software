# AquaTrack 💧

### AI-Powered Water Monitoring System

AquaTrack is a software prototype designed to demonstrate pipeline leak anomaly detection and water-quality indicator monitoring.

## Key Features

- Interactive water monitoring dashboard
- Sensor data visualization
- Rule-based leak anomaly classification
- Water-quality warning classification
- Alert generation
- Historical readings using SQLite
- Flask REST API integration

## Technology Stack

- Python
- Flask
- JavaScript
- HTML
- CSS
- SQLite

## Prototype Status

The current prototype uses simulated sensor inputs to demonstrate backend processing, event classification, database storage and dashboard functionality.

Physical sensor and ESP32 integration are planned for a future development phase.

## Run Locally

Install dependencies:

```bash
pip install -r requirements.txt
```

Start the application:

```bash
python app.py
```

Open `http://127.0.0.1:5000` in your browser.
